🔐 GitHub connection

Only someone with your GitHub token can publish. It is saved only in this browser.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only your portfolio repo. Permission: Contents → Read and write.
  3. Your site must deploy from this repo (GitHub Pages, Netlify or Vercel).

📊 Connect live analytics

Free, 2-minute setup with Firebase Realtime Database (no server needed).

  1. console.firebase.google.com → create/open a project → Build → Realtime Database → Create.
  2. Open the Rules tab, paste the rules below, press Publish.
  3. Copy the database URL (looks like https://xxxx-default-rtdb.firebaseio.com) and paste it here, then Publish the site once.
