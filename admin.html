📊 Visitor Analytics (Firebase Realtime Database)

Visitor Analytics চালু করার নিয়ম (মাত্র ২ মিনিট):
১. console.firebase.google.com এ গিয়ে একটি ফ্রি প্রজেক্ট খুলুন।
২. বাঁপাশের মেনু থেকে Build → Realtime Database → Create Database ক্লিক করুন।
৩. Rules ট্যাবে গিয়ে নিচের কোডটি পেস্ট করে Publish দিন:
{
  "rules": {
    ".read": false,
    ".write": false,
    "stats":    { ".read": true, ".write": true },
    "presence": { ".read": true, ".write": true }
  }
}
৪. উপরে থাকা ডেটাবেজ URL (যেমন https://xxx-default-rtdb.firebaseio.com) কপি করে এখানে পেস্ট করুন এবং Save All Changes চাপুন।

🔐 GitHub — Publish Settings

Your token is saved only in this browser (localStorage). Never shared.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only your portfolio repo. Permission: Contents → Read and write.
  3. Your site must deploy from that repo (GitHub Pages, Netlify, or Vercel).

📊 Connect Live Analytics

Free 2-minute setup using Firebase Realtime Database (no server needed).

  1. console.firebase.google.com → create project → Build → Realtime Database → Create
  2. Open Rules tab → paste rules below → Publish
  3. Copy the database URL and paste below → Save → Publish the site once
